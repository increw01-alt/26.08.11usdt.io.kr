## 2. 경쟁 분석: 김프가(kimpga.com)

### 2-1. 김프가의 강점 (정면승부 금지 영역)

| 항목 | 내용 |
|---|---|
| 시장 지위 | "김프" 카테고리 1위 브랜드. 실시간 동시접속 1,000명+ 수준 |
| 공식 제휴 | 빗썸과 파트너십. 빗썸 '글로벌 시세차이' 페이지에 데이터 공급 |
| 커버리지 | 국내(업비트·빗썸·코인원) × 해외(바이낸스·OKX·바이빗·비트겟·게이트·후오비) USDT 마켓 |
| 기능 폭 | 김프(코인) / 김프(금) / 선물 롱숏 지표 / 시가총액 통계 / 커뮤니티 / 뉴스 / 로그인·알림 |
| 실시간성 | WebSocket 기반 초단위 갱신 + TradingView 차트 |

**결론: 실시간 대시보드로는 이길 수 없고, 이길 필요도 없다.**

### 2-2. 김프가의 구조적 약점 (직접 크롤링으로 확인)

1. **완전 CSR(클라이언트 렌더링)** — HTML에 콘텐츠가 전혀 없음. 크롤러가 수집할 텍스트가 메타태그뿐.
2. **canonical이 전 페이지 홈으로 지정** — `/indicators/quotes` 같은 서브페이지조차 canonical이 `https://kimpga.com`. 서브페이지 색인을 구조적으로 포기한 상태. 롱테일 검색 유입 원천 차단.
3. **메타 키워드에 '테더/USDT' 누락** — 김프·비트코인·역프·재정거래는 있지만 USDT·테더가 없음. USDT 특화 검색 수요를 전혀 타겟하지 않음.
4. **교육·설명 콘텐츠 제로** — "김치프리미엄이란", "역프 뜻", "재정거래 세금" 같은 정보성 페이지가 없음.
5. **과거 기록 페이지 없음** — "2026년 1월 김프", "역대 김프 최고치" 검색을 받을 페이지가 없음.
6. **초보자 진입장벽** — 용어 설명 없는 트레이더용 대시보드.

### 2-3. 기회 요약

김프가는 **"이미 아는 사람이 매일 보는 도구"**다.
우리는 **"검색해서 처음 들어오는 사람이 이해하고 확인하는 정보 사이트"**를 만든다.
두 시장은 겹치지 않으며, 후자는 SEO로 잡을 수 있고 김프가는 구조상 여기 못 들어온다.

## 3. 포지셔닝: "디지털 달러 정보 사이트"

> **USDT는 '오늘의 디지털 달러', 컴퓨트달러는 '내일의 달러 패권 구조'.**
> usdt.io.kr은 테더 시세에서 출발해 디지털 달러 전반을 다루는 유일한 한국어 정보 사이트가 된다.

### 차별화 4축

**축 1 — USDT 전문화**
김프가에서 USDT는 상단 티커 하나. 우리는 USDT의 원화 시세, 달러 환율 대비 프리미엄, 거래소별 가격차, 네트워크별 수수료(TRC20/ERC20), 규제 이슈까지 전부 다룬다. "테더 = usdt.io.kr" 등식을 만든다. 2026 하반기 디지털자산기본법·원화 스테이블코인 입법이 9월 정기국회 분기점을 앞두고 있어 스테이블코인 검색량 급증 구간에 정확히 올라탄다.

**축 2 — SEO 콘텐츠**
페이지마다 고유 URL + 고유 canonical + 서버에 렌더링된 텍스트. 김프가가 구조적으로 포기한 검색 유입을 전부 흡수한다. 모두의시세 SSG 전환에서 검증한 방식 그대로.

**축 3 — 김프 히스토리 아카이브 (데이터 해자)**
매일 크론이 김프 스냅샷을 저장하고 날짜별 정적 페이지를 자동 생성. 시간이 지날수록 쌓이는, 후발주자가 복제할 수 없는 자산. "역대 김프", "작년 김치프리미엄" 검색 독점.

**축 4 — 매크로 인사이트 (컴퓨트달러 필러)** ★v2 신규
시세(도구) + 가이드(교육) 위에 매크로 분석 층을 얹는다. 국내 김프·시세 사이트 중 유일한 3층 구조. 컴퓨트달러·AI 에이전트 결제·스테이블코인 지정학 등 미래 키워드를 무주공산 상태에서 선점하고, 구글·네이버가 평가하는 '스테이블코인 토픽 권위'를 확보한다.

## 4. 컴퓨트달러 브리핑 (인사이트 필러의 배경 지식)

### 4-1. 개념

**컴퓨트달러(Compute Dollar) = 페트로달러의 AI 시대 후계 구조.**
석유 결제가 달러 패권을 지탱했던 것처럼, AI 컴퓨팅 인프라와 스테이블코인이 새로운 달러 수요를 만들어낸다는 거시경제 프레임. 2026년 7월 말 해외 칼럼(Project Syndicate 계열, Korea Times·Taipei Times 게재)을 통해 확산되기 시작한 최신 개념.

### 4-2. 에너지-컴퓨트-달러 루프

```
전기(에너지) → 데이터센터 → 컴퓨트(AI 연산력)
    → 비즈니스 자동화 · AI 에이전트 결제 (프로그래머블 결제 선호)
    → 스테이블코인 수요 증가
    → 스테이블코인 준비금이 미국 국채로 유입
    → 미국 금융시장·달러 지배력 강화 → (순환)
```

핵심 특징: 페트로달러는 정부 간 공식 합의로 구축됐지만, 컴퓨트달러 루프는 **누구도 지휘하지 않는 상업적 결정들의 집합**으로 형성되고 있다. 클라우드 기업이 부지·전력을 확보하고, AI 기업이 모델을 서비스로 패키징하고, 결제 기업이 스테이블코인 레일을 깔고, 발행사가 미 국채를 사들이는 각각의 합리적 선택이 합쳐져 달러 패권을 재강화한다.

### 4-3. 루프를 구성하는 실제 사건들 (콘텐츠 소재)

- **Cloudflare NET Dollar** (2025.9 발표): AI 에이전트·에이전틱 웹의 즉시 결제를 위한 달러 기반 스테이블코인. 마이크로페이먼트·사용량 과금·크리에이터 보상이 목표. Coinbase와 x402 재단 설립.
- **Google AP2** (2025.9): Coinbase·이더리움재단·PayPal 등이 참여한 AI 에이전트 결제 프로토콜.
- **미국 GENIUS Act** (2025 통과): 스테이블코인 발행·유통 규제 명확화 → 시장 성장 가속. 스테이블코인 시가총액 3,000억 달러 돌파.
- **한국 디지털자산기본법·원화 스테이블코인** (2026 하반기 입법 추진): 컴퓨트달러 프레임에서 원화 스테이블코인의 위치를 논할 수 있는 국내 접점.

### 4-4. 왜 지금 선점인가

- "컴퓨트달러" 한국어 검색 결과가 사실상 **무주공산** (2026-08-11 검색 확인 — 개념을 다루는 국내 페이지 부재).
- 국내 영자지에 칼럼이 실리기 시작한 단계 → 국내 경제지·유튜브가 용어를 받아쓰는 순간 선점 페이지가 검색 독식. 모두의시세 초기 카테고리 키워드 선점과 동일한 플레이.
- 단, **현재 검색량은 거의 0** → 즉시 트래픽용이 아닌 미래 파도 선점용. 관련 중간 검색량 키워드(페트로달러, 달러 패권, 스테이블코인 전망, 스테이블코인 국채)로 현재 트래픽을 받치고, 앵커 글이 파도를 기다리는 구조로 설계한다.

## 7. 기술 구현 (기존 인프라 재활용)

### 파이프라인

```
GitHub Actions (cron: */10 * * * *)
  └─ collect.py
      ├─ 업비트 REST: /v1/ticker?markets=KRW-USDT,KRW-BTC…  (무료·키 불필요)
      ├─ 빗썸 REST: /public/ticker/USDT_KRW              (무료)
      ├─ Binance REST: /api/v3/ticker/price (BTCUSDT 등)  (무료)
      └─ 환율: 한국수출입은행 open API (무료·공식)
  └─ build.py
      ├─ data/latest.json 갱신
      ├─ data/2026-08-11.json 일별 누적 (하루 1회 스냅샷 커밋)
      ├─ 시세 페이지 HTML 재생성 (템플릿 + 데이터 주입)
      └─ sitemap.xml 갱신
  └─ git commit & push → Cloudflare Pages 자동 배포
```

### 필수 체크리스트 (모두의시세 교훈 반영)

- [ ] **`timeout-minutes: 10`** 워크플로에 반드시 명시 (좀비 잡 → 무료 티어 소진 방지)
- [ ] **`requests.get(url, timeout=10)`** 모든 API 호출에 타임아웃
- [ ] API 실패 시 직전 데이터 유지 + "N분 전 기준" 표시 (빈 페이지 배포 금지)
- [ ] 크론 10분 주기면 월 4,320회 실행 — 1회 1분 이내 유지 시 무료 한도 내
- [ ] 일별 JSON 커밋은 하루 1회만 (커밋 히스토리 오염 방지, 10분 갱신분은 latest.json 덮어쓰기)

### 프론트

- 정적 HTML + Tailwind CDN + Pretendard (기존 9브랜드 디자인 토큰 시스템 tokens.css 재활용)
- 차트: Chart.js 24h/7d 미니 차트 — 빌드 시점 데이터를 인라인 JSON으로 심어 크롤러에게도 수치 텍스트 노출
- "실시간" 표방 금지 → **"10분마다 갱신 · HH:MM 기준"** 명시 (신뢰도 + 법적 안전)
- /insight/ 글은 롱폼 아티클 템플릿(목차·출처 박스·관련 글) 별도 제작 — 매크로 콘텐츠의 체류시간 극대화

### SEO 세팅

- 페이지별 고유 title/description/canonical (김프가의 실패를 뒤집는 지점)
- 구조화 데이터: Article(가이드·인사이트), FAQPage(가이드), Table/Dataset(시세·히스토리)
- 구글 서치콘솔 + **네이버 서치어드바이저** 동시 등록 (김프 검색은 네이버 비중 큼)
- 네이버 SEO 스킬(naver-seo-skill) 적용, 제목·훅은 ad-copy-inspiration 스킬로 최적화
- 인사이트 필러는 구글 디스커버 노출 가능성 있음 → 대표 이미지 1200px, 명확한 발행일·수정일 메타 관리
