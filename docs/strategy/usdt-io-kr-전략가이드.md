## 1. 김프가 분석 결과

### 1-1. 김프가의 강점 (정면승부 금지 영역)

| 항목 | 내용 |
|---|---|
| 시장 지위 | "김프" 카테고리 1위 브랜드. 실시간 동시접속 1,000명+ 수준 |
| 공식 제휴 | 빗썸과 파트너십 체결. 빗썸 '글로벌 시세차이' 페이지에 데이터 공급 |
| 커버리지 | 국내(업비트·빗썸·코인원) × 해외(바이낸스·OKX·바이빗·비트겟·게이트·후오비) USDT 마켓 |
| 기능 폭 | 김프(코인) / 김프(금) / 선물 롱숏 지표 / 시가총액 통계 / 커뮤니티 / 뉴스 / 로그인·알림 |
| 실시간성 | WebSocket 기반 초단위 갱신 + TradingView 차트 |

**결론: 실시간 대시보드로는 이길 수 없고, 이길 필요도 없다.**

### 1-2. 김프가의 구조적 약점 (직접 크롤링으로 확인)

kimpga.com을 직접 fetch한 결과, 다음이 확인됨:

1. **완전 CSR(클라이언트 렌더링)** — HTML에 콘텐츠가 전혀 없음. 크롤러가 수집할 텍스트가 메타태그뿐. 모두의시세에서 이미 확인한 것과 동일한 문제를 김프가는 방치하고 있음.
2. **canonical이 전 페이지 홈으로 지정** — `/indicators/quotes` 같은 서브페이지조차 canonical이 `https://kimpga.com`. 서브페이지 색인을 구조적으로 포기한 상태. 롱테일 검색 유입이 원천 차단됨.
3. **메타 키워드에 '테더/USDT'가 없음** — 김프,비트코인,이더리움,역프,재정거래… 는 있지만 USDT·테더는 누락. USDT 특화 검색 수요를 전혀 타겟하지 않음.
4. **교육·설명 콘텐츠 제로** — "김치프리미엄이란", "역프 뜻", "재정거래 세금" 같은 정보성 페이지가 없음. 숫자만 보여주는 트레이더용 도구.
5. **과거 기록 페이지 없음** — 실시간만 있고 "2026년 1월 김프", "역대 김프 최고치" 같은 히스토리 검색을 받을 페이지가 없음.
6. **초보자 진입장벽** — 용어 설명 없이 대시보드만 존재. 뉴스 보고 처음 김프를 검색한 사람이 이해할 콘텐츠가 없음.

### 1-3. 기회 요약

김프가는 **"이미 아는 사람이 매일 보는 도구"**다.
우리는 **"검색해서 처음 들어오는 사람이 이해하고 확인하는 정보 사이트"**를 만든다.
두 시장은 겹치지 않으며, 후자는 SEO로 잡을 수 있고 김프가는 구조상 여기 못 들어온다.

## 2. usdt.io.kr 포지셔닝

> **"테더(USDT) 특화 시세·김프 정보 사이트"**
> 김프가 = 전 코인 실시간 대시보드 / usdt.io.kr = USDT 하나를 가장 깊게

### 차별화 3축

**축 1 — USDT 전문화**
김프가에서 USDT는 상단 티커 하나. 우리는 USDT의 원화 시세, 달러 환율 대비 프리미엄, 거래소별 가격차, 네트워크별 수수료(TRC20/ERC20), 스테이블코인 규제 이슈까지 전부 다룬다. "테더 = usdt.io.kr" 등식을 만든다. 2026 하반기 디지털자산기본법·원화 스테이블코인 입법이 국회 정기국회(9월) 분기점을 앞두고 있어, 스테이블코인 검색량 급증 구간에 정확히 올라탈 수 있다.

**축 2 — SEO 콘텐츠 (김프가가 구조적으로 못 잡는 영역)**
페이지마다 고유 URL + 고유 canonical + 서버에 렌더링된 텍스트. 모두의시세 SSG 전환에서 검증한 방식 그대로.

**축 3 — 김프 히스토리 아카이브 (데이터 해자)**
매일 크론이 김프 스냅샷을 저장하고 날짜별 정적 페이지를 자동 생성. 시간이 지날수록 데이터가 쌓이고, 후발주자가 복제할 수 없는 자산이 된다. "역대 김프", "작년 김치프리미엄" 검색을 독점.

## 5. 기술 구현 (기존 인프라 재활용)

### 파이프라인
```
GitHub Actions (cron: */10 * * * *)
  └─ collect.py
      ├─ 업비트 REST: /v1/ticker?markets=KRW-USDT,KRW-BTC…  (무료·키 불필요)
      ├─ 빗썸 REST: /public/ticker/USDT_KRW              (무료)
      ├─ Binance REST: /api/v3/ticker/price (BTCUSDT 등)  (무료)
      └─ 환율: 한국수출입은행 open API (무료, 공식)
  └─ build.py
      ├─ data/latest.json 갱신
      ├─ data/2026-08-11.json 일별 누적 (하루 1회 스냅샷 커밋)
      ├─ 시세 페이지 HTML 재생성 (템플릿 + 데이터 주입)
      └─ sitemap.xml 갱신
  └─ git commit & push → Cloudflare Pages 자동 배포
```

### 필수 체크리스트 (모두의시세에서 얻은 교훈 반영)
- [ ] **`timeout-minutes: 10`** 워크플로에 반드시 명시 (좀비 잡 → 무료 티어 소진 방지)
- [ ] **`requests.get(url, timeout=10)`** 모든 API 호출에 타임아웃
- [ ] API 실패 시 직전 데이터 유지 + "N분 전 기준" 표시 (빈 페이지 배포 금지)
- [ ] 크론 10분 주기면 월 4,320회 실행 — 1회 1분 이내로 끝나게 유지하면 무료 한도 내
- [ ] 일별 JSON 커밋은 하루 1회만 (커밋 히스토리 오염 방지, 10분 갱신분은 latest.json 덮어쓰기)

### 프론트
- 정적 HTML + Tailwind CDN + Pretendard (기존 9브랜드 디자인 토큰 시스템 tokens.css 재활용)
- 차트: Chart.js로 24h/7d 미니 차트 — 빌드 시점 데이터를 인라인 JSON으로 심어 크롤러에게도 수치 텍스트 노출
- "실시간" 표방 금지 → **"10분마다 갱신 · HH:MM 기준"** 명시 (신뢰도 + 법적 안전)

### SEO 세팅
- 페이지별 고유 title/description/canonical (김프가의 실패를 뒤집는 지점)
- 구조화 데이터: Article, FAQPage (가이드), Table/Dataset (시세·히스토리)
- 구글 서치콘솔 + **네이버 서치어드바이저** 동시 등록 (김프 검색은 네이버 비중 큼)
- 네이버 SEO 스킬(naver-seo-skill) 적용: 가이드 콘텐츠를 네이버 검색 로직에 맞게 최적화
