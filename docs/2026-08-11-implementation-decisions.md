# 구현 결정 기록 (2026-08-11)

전략 가이드 v2를 확정 스펙으로 채택하고 구축하면서 내린 기술 결정들.

| 결정 | 내용 | 이유 |
|---|---|---|
| CSS | Tailwind CDN 대신 자체 tokens.css + site.css | Tailwind CDN은 런타임 JS ~100KB로 렌더 차단·SEO에 불리. 기존 9브랜드 tokens.css는 이 리포에 없어 신규 작성 |
| 차트 | Chart.js 대신 자체 SVG 렌더러(chart-mini.js) | 외부 의존성 제로, 다크모드 토큰 연동, 크로스헤어+툴팁 구현. 데이터는 빌드 시점 인라인 JSON → 크롤러에게 수치 텍스트 노출 |
| HTTP | requests 대신 urllib (표준 라이브러리) | CI에서 pip install 단계 제거, 로컬 의존성 제로. 가이드의 핵심 요구(모든 호출 timeout=10)는 동일 충족 |
| 환율 | EXIM_API_KEY 있으면 수출입은행, 없으면 exchangerate-api 무료 소스 | 수출입은행 API는 키 발급 필요 + 주말·장전 빈 응답 → 무료 소스 폴백으로 무중단 |
| 콘텐츠 구조 | 완성 HTML 대신 프래그먼트+메타 JSON → build.py가 조립 | 22편의 헤더/푸터/메타 일관성 보장, 디자인 변경 시 전체 재생성 가능, canonical·JSON-LD 자동화 |
| 등락률 표기 | 업비트 "(전일比)" / 빗썸 "(24h)" 구분 표기 | 업비트 API는 전일 종가 대비, 빗썸은 24시간 대비 — 동일 표기 시 부정확 |
| 색상 | 김프 양수=적색, 음수(역프)=청색 | 국내 시장 관행. 부호(+/-)와 항상 병기해 색맹 안전. 차트 팔레트는 dataviz 검증 스크립트 통과값 |
| 히어로 카피 | "디지털 달러의 기준" (태그라인) / "달러는 하나, 가격은 둘" (서브) | ad-copy-inspiration 스킬 패턴(초간결 선언형·대조법) 변형. 원본 카피 5어절 이상 일치 없음 확인 |
