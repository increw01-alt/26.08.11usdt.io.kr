# 테더뷰 상세페이지 참고자료 적용 메모

## 자료 위치

`references/USDT_DETAIL_PAGE_REFERENCE_PACKAGE_2026-08-31/`

이 묶음은 상세페이지의 정보 구조, 시각 구성, 애니메이션과 검수 기준을 참고하기 위한 자료다. 참고 HTML의 한국상품권협회 브랜드, 전화번호, 채널톡 주소, canonical, 도메인, 정책 문구와 수치는 테더뷰에 그대로 복사하지 않는다.

## 기본 작성 순서

1. 테더뷰 공통 상단 동영상과 메뉴
2. 현재 위치
3. 제목, 도입 요약, 첫 이동 버튼
4. 핵심 확인 3~4개
5. 본문 목차
6. 장문 카드형 본문
7. FAQ 4~6개
8. 공식 출처와 검토일
9. 테더뷰 서비스 범위 및 투자 위험 고지
10. 테더뷰 공통 푸터

## 콘텐츠 원칙

- H1은 한 개만 사용하고 핵심 검색어를 앞부분에 자연스럽게 배치한다.
- H2 아래 첫 문단에서 결론을 먼저 제시한다.
- 한 카드에는 하나의 질문이나 주제만 담는다.
- 긴 설명은 단계 카드, 안전 목록, 비교표, 핵심·안내·주의 박스로 나눈다.
- 수치, 정책, 수수료와 지원 조건은 작업 시점의 공식 출처로 다시 확인한다.
- 근거 우선순위는 정부·금융당국 → 발행사·프로토콜 → 거래소·지갑 공식 문서다.
- “항상”, “무조건”, “100%”, 수익·승인 보장 같은 단정 표현은 사용하지 않는다.
- 화면 FAQ와 FAQ 구조화 데이터의 질문·답변을 일치시킨다.
- 공개 전에는 `noindex,nofollow`를 유지하고, 승인 후에만 canonical과 공개 설정을 변경한다.

## 재사용할 구성 요소

- `article-v1-intro`: 제목과 도입
- `article-v1-notice`: 핵심 확인
- `article-v1-toc`: 목차와 현재 섹션 강조
- `article-v1-section`: 장문 본문 카드
- `article-v1-step-list`: 단계형 절차
- `article-v1-safety-list`: 안전 확인 목록
- `article-v1-table-wrap`: 데스크톱 표와 모바일 카드형 행
- `article-v1-key-box`: 핵심 결론
- `article-v1-info-box`: 보충 안내
- `article-v1-warning`: 착오·손실·정책 주의
- `article-v1-faq-list`: FAQ
- `article-v1-sources`: 공식 출처와 검토일

## 모션 기준

- 큰 영역: `up`, `left`, `right`, `scale` 중 의미에 맞는 값을 직접 지정한다.
- 큰 영역은 약 8% 화면 진입 시 한 번만 나타난다.
- 단계, 체크 항목, 표 행과 FAQ는 약 0.06초 간격으로 순차 등장한다.
- 데스크톱 큰 영역 0.72초, 내부 항목 0.55초를 기준으로 한다.
- 모바일에서는 좌우 이동을 아래에서 위로 바꾸고 내부 항목은 약 0.44초로 줄인다.
- `prefers-reduced-motion`에서는 숨김이나 이동 없이 즉시 표시한다.
- JavaScript가 꺼져도 본문은 처음부터 보여야 한다.

## 테더뷰에 적용할 때의 우선순위

- 테더뷰의 현재 공통 헤더, 상단 동영상, 메뉴, 색상, Pretendard 글꼴과 정적 빌더 구조를 유지한다.
- 참고본의 Tailwind CDN과 다른 사이트 전용 전역 스타일은 그대로 추가하지 않는다. 필요한 `article-v1-*` 규칙만 테더뷰 범위에 맞춰 이식한다.
- 장문 상세 글의 공통 히어로에는 `bitcoin-main.mp4`를 사용한다. 목록·차트·계산기 허브 등 일반 하부 페이지는 `bitcoin-main-2.mp4`를 유지한다.
- 상세 본문 안에는 별도의 자동재생 영상을 추가하지 않는다.
- 협회 배너, 상담 채널, 전화번호 등 테더뷰에 없는 정보는 사용자가 별도로 제공하거나 승인하기 전까지 넣지 않는다.
- 참고 페이지의 본문과 숫자를 복제하지 않고 새 주제에 맞춰 공식 출처로 다시 작성한다.

## 완료 전 검수

- 데스크톱 1440×1000과 모바일 390px 확인
- H1 한 개, 목차와 섹션 ID 일치
- 가로 스크롤, 제목 잘림, 버튼 겹침, 빈 이미지 없음
- 모바일에서 비교표가 카드형 행으로 전환
- 이미지와 내부 링크 정상 응답
- 브라우저 오류 없음
- FAQ 화면과 구조화 데이터 일치
- 공식 출처, 검토일, 정보 제공 및 투자 위험 고지 포함
- 축소 모션 환경에서 모든 콘텐츠 즉시 표시
- 별도 요청 전 커밋·푸시·배포 금지
